These numbers come from this server's own access log — the record it keeps of every request it answers, which it would write down whether anyone read it or not. There is no analytics service, no cookie and no script reporting anything about you: the page you are reading fetches a single small file of totals, and nothing about a visitor travels the other way.

A visit is a run of requests from one address with no half-hour gap. Search engines and the link scanners that sit in front of university mailboxes are counted the same as anyone else, because from the server's side they are indistinguishable from a reader — so read the total as traffic, not as people.

The country comes from the address blocks the five regional internet registries publish, matched offline. No address is stored here, and none is shown.
