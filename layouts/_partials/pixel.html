{{- /* GitHub Pages keeps no access log and offers no way to read one, so a visit to the mirror is invisible. This asks the browser for a 1x1 image from the host that *does* keep a log, which puts the visit in it. Only on the mirror: on boyuezhang.com the page request is already logged, and a pixel there would count everything twice. The two builds differ by baseURL — the server passes --baseURL, Actions takes it from hugo.toml — so which build this is can be decided here rather than at run time, and the tag simply is not in the mirror's sibling. It is a tracking pixel, and a content blocker may well drop it. That costs a count and nothing else: no layout depends on it, and it carries no script. */ -}} {{- /* Matched against the mirror's own address, not merely "anything that is not the canonical host": `hugo server` builds with a localhost baseURL, which the looser test read as the mirror, so every local preview put a hit in the production log. */ -}} {{- $canonical := site.Params.canonicalHost -}} {{- $mirror := site.Params.mirrorHost -}} {{- if and $canonical $mirror (eq (strings.TrimSuffix "/" site.BaseURL) (strings.TrimSuffix "/" $mirror)) -}} {{- end -}}
