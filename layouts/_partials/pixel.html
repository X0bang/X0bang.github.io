{{- /* GitHub Pages keeps no access log and offers no way to read one, so a visit to the mirror is invisible. This asks the browser for a small image from the host that *does* keep a log, which puts the visit in it. The page it stands for is carried in the path rather than a query string, and the file is one of a handful of ordinary asset names chosen from the path, so the request has the shape of a stylesheet's worth of icons rather than of a counter. A blocklist matches on that shape; nothing here hides it from anyone who opens the page source, and it is not meant to. Only on the mirror. Matched against the mirror's own address rather than "anything that is not canonical", because `hugo server` builds with a localhost baseURL and the looser test reported every local preview. */ -}} {{- $canonical := site.Params.canonicalHost -}} {{- $mirror := site.Params.mirrorHost -}} {{- if and $canonical $mirror (eq (strings.TrimSuffix "/" site.BaseURL) (strings.TrimSuffix "/" $mirror)) -}} {{- $path := strings.TrimPrefix "/" (strings.TrimSuffix "/" .RelPermalink) -}} {{- $names := slice "logo1" "logo2" "icon" "mark" -}} {{- $name := index $names (mod (hash.FNV32a .RelPermalink) (len $names)) -}} {{- $src := printf "%simages/marks/%s%s.svg" $canonical (cond (eq $path "") "" (printf "%s/" $path)) $name -}} {{- end -}}
